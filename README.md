本项目集合了两个独立的 Python 小脚本，分别用于：

两者均为命令行交互式运行，无需第三方依赖。

## 一、培根密码解密.py

### 原理简介

培根密码（Bacon's Cipher）使用 5 位 A/B 字母组合表示一个字母。常见变体：

- **标准解密**：`i/j` 共用、`u/v` 共用，共 24 个字母（对应 `letters2` / `cipher2`）
- **新式解密**：26 个字母独立编码（对应 `letters1` / `cipher1`）

### 大小写映射

密文通常通过字母大小写隐藏 A/B 位，脚本支持两种映射：

- `大写A，小写B`：大写字母 → A，小写字母 → B
- `大写B，小写A`：大写字母 → B，小写字母 → A

## 二、not_md5_encode.py

### 工具简介

这是一个用于处理**非标准 MD5 字符串**的小工具。

在 CTF 比赛、渗透测试靶场等场景中，经常会遇到一些被人为"污染"的 MD5 值——比如在标准 32 位十六进制 MD5 中混入了其他字符（如 `g`~`z`、符号、空格等），导致长度不是 32 位、无法直接用于解密或比对。

本工具的作用就是**剔除所有非十六进制字符**，还原出纯净的 MD5 字符串，并输出其长度，方便后续拿去解密平台（如 cmd5、somd5 等）查询。

---
### 功能说明
- 接收用户输入的一段"脏" MD5 字符串
- 遍历每个字符，凡是不在 `0-9` 和 `a-f` 范围内的字符全部删除
- 输出清洗后的字符串及长度
- 等待用户按回车退出
